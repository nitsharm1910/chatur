# Chatur 0.9.0

**The first public release of Chatur: a governed, auditable AI harness for the whole software
lifecycle, with full Claude Code support.**

## Highlights
- **Agents can't commit, push, approve, or leak secrets.** A policy engine checks every tool call; shell
  tricks are analysed, and anything unclear goes to a human.
- **A real SDLC in your assistant:** nine role agents with enforced write scopes and `/chatur-*` commands
  from requirements to release, with human-approved gates bound to the exact documents approved.
- **A record you can trust:** a hash-chained, secret-masked audit log of every action, and ADRs for every decision.
- **Defense in depth:** the same rules at commit time and in CI, for any committer and any assistant.

## Install
```bash
pipx install chatur
chatur init && chatur hooks install claude && chatur primitives install claude
chatur git-hooks install && chatur ci install github
```
APM users: `apm install nitsharm1910/chatur#v0.9.0`.

## Supported assistants
| Assistant | Support |
|---|---|
| Claude Code | Full: enforcing hooks, agents, commands, skills, rules |
| GitHub Copilot | Instructions/agents/skills via APM; enforcing adapter in **1.0** |
| Codex, Gemini CLI, Cursor | Instructions/agents/skills via APM; git/CI backstop enforces the rules |

## Known limitations
- `git commit --no-verify` skips local hooks; CI is authoritative.
- Commands inside scripts and repo-level git aliases can't be resolved statically (they still need
  approval, and the backstop catches the outcome).
- Behaviour of hook `ask` in Claude's `acceptEdits` / `bypassPermissions` modes is not yet verified.
- 0.x: public interfaces may change in minor releases (each change gets an ADR and a changelog entry).
