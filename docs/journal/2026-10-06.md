# Journal — 2026-10-06

## Actions
- **Walkthrough finding (maintainer, 3.8c):** `chatur gate approve requirements` prompted
  `Type 'requirements' to approve this gate:`. The maintainer reasonably typed the PRD name (`PRD-tasks-cli`)
  and got "confirmation did not match". The prompt didn't say what was being approved or what to type.
- **Fix (UX only; ADR-0021 semantics unchanged; a typed confirmation is still required):**
  - `gates.ConfirmRequest` (action, phase, approver, details). The confirmation callback receives the full
    picture: the artifact files being approved (first 10, then "... and N more"), a re-approval notice for
    stale gates, and for revoke the list of gates that cascade.
  - **All preconditions run before the prompt** (phase order, artifacts exist, audit intact), so the human is
    never asked to confirm something that will fail.
  - CLI prompt: a summary block, then `To confirm, type the phase name: <phase>`; case-insensitive; up to 3
    attempts with a hint (`You typed 'X'. Type the phase name 'requirements' itself (not a file or feature
    name)`); empty line or Ctrl+C cancels. Error on cancel: `not confirmed; the '<phase>' gate was not changed`.
  - Tests: preview contents, re-approval flag, truncation, revoke cascade preview, preconditions-before-prompt,
    terminal prompt (exact, case/space-insensitive, mistake-then-correct, 3 wrong, empty, Ctrl+C).
