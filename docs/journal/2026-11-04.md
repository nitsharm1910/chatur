## Fixes for 0.9.0 (ADR-0034, Accepted)
- `rule_from_instructions` emits no `paths:` when every `applyTo` pattern is `**`. The source keeps `applyTo` because Copilot receives it unchanged; this corrects ADR-0033's draft, which said to drop it.
- `git.no-history-rewrite`: `git tag` is denied unless every argument matches a read-only shape; `git reflog` is denied only for expire/delete/drop.
- Native deny rules: the broad `git tag` rule is replaced by its write flags. Trade-off: with Chatur not running, a plain `git tag v1` isn't stopped natively (it stays local; push is still denied).
- Tests: 14 read-only forms ask; 21 write forms deny, including nested shells and chains; rule conversion; native rules. Suite: 1046 passed, 3 expected skips.
- CHANGELOG 0.9.0 date moved to 2026-11-04 and limitations added; change the date if the tag lands later.
