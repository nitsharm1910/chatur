## Phase 5: git and CI backstop
- Maintainer decisions: block agent-session commits, secrets, tampered governance, and profile process gaps; AI trailers warn only; native hooks + pre-commit framework; GitHub Actions + generic CI → **ADR-0030 (Accepted)**.
- Key design point: in-session rules aren't re-run at commit time (meanings differ, e.g. a human committing `state.json` after approving is correct). Explicit checks each declare the rules they back; a test requires every critical git/ci rule to be covered.
- Built: `backstop.py` (git facts via the CLI; checks: agent-session, secrets, governance incl. approval↔audit-record consistency, stale gates, process via synthetic events + profile rules, history-rewrite, AI trailers, committed tooling; text, GitHub-annotation, and step-summary output), `githooks.py` (hook scripts with marker; refuses foreign hooks and `core.hooksPath` unless `--force`; GitHub workflow template), CLI `git-hook`, `git-hooks install|uninstall`, `ci-check`, `ci install github`, root `action.yml` (inputs via env), `.pre-commit-hooks.yaml` (handles the framework's `PRE_COMMIT_FROM_REF/TO_REF`).
- Tests (`tests/test_backstop.py`) against real temporary git repos, including an end-to-end run where the installed hook blocked a commit containing a token and a commit from an agent-session env, while a clean human commit went through.
- Fixed during testing: a token line was also reported as a credential shape; a known token now supersedes the generic finding.
- **Dogfood: `ci-check` over Chatur's whole history** found:
  - 2 blocking: literal fake PEM private-key blocks in `tests/test_redact.py` and `tests/test_guard_secrets.py`, breaking our own "build fake secrets at runtime" convention. Fixed; CI clears once committed (it scans committed history).
  - ~45 credential false positives in code and prose (`redact_secrets=False`, `wildcard-token rules`, `a shell token containing…`, `contains_secret = "token"`, `token = _glob_regex(path)`). Detection refined: flags must start a word; `token` counts only after `Authorization:`; credential values must be ≥6 chars with a digit or symbol (or ≥12 chars) and not a keyword or code reference/call. Masking stays aggressive. Regression tests for every false positive and for real shapes.
  - Noise: 29 identical design-gate warnings → identical findings beyond 3 are grouped on one line.
- Chatur's own CI gains a `backstop` job using `uses: ./` (dogfoods `action.yml`).
- Suite: 999 passed, 3 expected skips.
