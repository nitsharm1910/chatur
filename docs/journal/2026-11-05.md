# Journal — 2026-11-05

## Actions
- **CI failure (maintainer):** GitHub rejected `action.yml` ("Mapping values are not allowed in this context", line 4, col 29).
  Cause: the unquoted `description: Chatur backstop: policy validity, ...` contains `: `, which YAML reads as a second mapping.
  This broke the `backstop` job (`uses: ./`) and would have broken every user of the action.
- **Fix:** quoted the description. A scan of `.pre-commit-hooks.yaml`, `apm.yml`, and the workflows found no other occurrence.
- **Why tests missed it:** nothing parsed the YAML (the runtime is stdlib-only and has no YAML library). Added
  `tests/test_release.py::test_yaml_files_have_no_unquoted_colon_values`, a small linter for this exact mistake (skips block scalars
  such as `run: |`), plus a test that it flags the reported line and ignores block scalars.
- Suite: 1048 passed, 3 expected skips.
